# ALV Form Online

Production-ready South African **Application for Licensing of Motor Vehicle (ALV)** online completion, official PDF population, printing, and signed document submission platform.

## Architecture Overview

- **Frontend**: React 19, TypeScript, Tailwind CSS v4, Vite 8 (`src/App.tsx`, `src/components/alv/`, `src/components/ZipInspectorSection.tsx`).
- **Backend**: Node.js + Express 4 (`server.ts`, `src/server/routes.ts`, `server/zipRoutes.ts`) serving:
  - `GET /api/health` — readiness and dependency health probe
  - `POST /api/generate-pdf` — strict Zod validation, sanitization, Python engine invocation, and verified storage
  - `GET /api/download?id=...&type=generated&disposition=attachment|inline` — path-confined attachment download or inline browser viewing/printing
  - `POST /api/upload-signed` — multipart PDF upload with extension, MIME, size, and `%PDF-`/`%%EOF` signature verification
  - `POST/GET/DELETE /api/zip-uploads` — ZIP archive inspection & persistence inside `uploaded-zips/<id>/files/` with PK magic-byte verification, ZIP-slip path confinement, size/entry caps, and `nosniff` + sandbox CSP headers on file reads
- **PDF Engine**: Python 3.9+ + PyMuPDF (`fitz`) (`src/lib/alv/fill_alv.py`) populating the official 2-page blank PDF (`src/lib/alv/ALV_blank.pdf`) using exact coordinates in `src/lib/alv/field_map.json` generated by `scripts/build_field_map.py`.
- **Storage**: Pluggable abstraction (`src/lib/storage/`):
  - `LocalStorageProvider` (`STORAGE_PROVIDER=local`) stores generated PDFs in `public/generated/` and signed uploads separately in `public/signed/`.
  - `ObjectStorageProvider` (`STORAGE_PROVIDER=s3`) uses `@aws-sdk/client-s3` for S3-compatible object storage (`generated/` and `signed/` prefixes) in production.
  - Persisted ZIP workspaces are stored in `uploaded-zips/<id>/files/` (configurable via `UPLOADED_ZIPS_DIR`).

## Official ALV PDF Mapping Notes

- Source form: `ALV(9)(2011/07)` (`src/lib/alv/ALV_blank.pdf`, 2 pages, `595.26 x 841.86` pt).
- Inspection via `scripts/build_field_map.py` shows the supplied official PDF uses Corel vector-drawn character boxes (`isAcroFormPdf: false`, `0` AcroForm widgets).
- `build_field_map.py` extracts closed vector cells and selection boxes from the PDF geometry and maps **48 fields** across **690 character/date cells** and **20 selection boxes**, with zero duplicate cell assignments.
- `fill_alv.py` supports AcroForm widget population and flattening if an AcroForm template is supplied, and precision character-cell + `X` selection-box rendering on the official vector PDF.
- **Signature & Office-Use Fields**: The `Signature / Handtekening` line on Page 2 is intentionally left blank for wet-ink signing after printing. All `FOR OFFICE USE ONLY` fields remain unmapped.

## Prerequisites & Setup

### Linux / macOS

```bash
# 1. Install Node.js dependencies
npm install

# 2. Install Python 3 and PyMuPDF
sudo apt-get update && sudo apt-get install -y python3 python3-fitz
# Or via pip:
# python3 -m pip install pymupdf

# 3. Configure environment variables
cp .env.example .env

# 4. (Optional) Re-inspect PDF and regenerate field_map.json
python3 scripts/build_field_map.py

# 5. Start development server on port 3000
npm run dev
```

### Windows (PowerShell)

```powershell
# 1. Install Node.js dependencies
npm install

# 2. Install Python 3.9+ and PyMuPDF
python -m pip install pymupdf

# 3. Configure environment variables
Copy-Item .env.example .env
# Optionally set PYTHON_EXECUTABLE=python in .env (auto-detected on Windows)

# 4. Start development server on port 3000
npm run dev
```

## Environment Variables

See `.env.example`:

- `PORT` — HTTP server port (default `3000`)
- `PYTHON_EXECUTABLE` — Override Python binary (`python` on Windows, `python3` on Linux/macOS when unset)
- `PYTHON_TIMEOUT_MS` — Max execution time per PDF job (default `15000`)
- `STORAGE_PROVIDER` — `local` or `s3`
- `GENERATED_PDF_DIR` / `SIGNED_PDF_DIR` / `UPLOADED_ZIPS_DIR` — Local directories when `STORAGE_PROVIDER=local`
- `S3_ENDPOINT`, `S3_REGION`, `S3_BUCKET`, `S3_ACCESS_KEY_ID`, `S3_SECRET_ACCESS_KEY`, `S3_FORCE_PATH_STYLE` — S3-compatible configuration
- `MAX_UPLOAD_BYTES` — Upload cap in bytes (default `10485760` = 10 MB)
- `PDF_RETENTION_HOURS` — Automated expiry window for stored files (default `24`)
- `RATE_LIMIT_WINDOW_MS` / `RATE_LIMIT_MAX_REQUESTS` — Sliding-window IP rate limit

## Deployment, Security & POPIA Operations

- **Runtime Hosting**: Deploy on a persistent container or VM runtime (e.g., Cloud Run, Fly.io, Railway, ECS, or Docker/Linux VM) where Node.js 22+, Python 3.9+, and PyMuPDF are installed together. Purely static/serverless Edge runtimes (such as standard Vercel Serverless Functions without an external backend) cannot reliably spawn Python + PyMuPDF or rely on ephemeral `/tmp` storage across download/upload requests; if hosting the frontend on Vercel, route `/api/*` to a persistent container backend service.
- **Persistent Storage**: Set `STORAGE_PROVIDER=s3` in production so generated and signed PDFs persist outside container ephemeral disks, with bucket-level encryption and private ACLs.
- **POPIA Compliance & Retention**: Temporary JSON inputs are deleted immediately after each Python run. Stored PDFs are never publicly listed, signed documents have no public download endpoint, and `server.ts` executes periodic retention cleanup every hour based on `PDF_RETENTION_HOURS`.
- **Logging & Monitoring**: Structured error logs are emitted to stderr with error codes (`PYTHON_NOT_FOUND`, `TEMPLATE_NOT_FOUND`, `PYTHON_TIMEOUT`, `PYTHON_PROCESSING_FAILED`) without logging sensitive South African ID numbers or personal payloads. Monitor `GET /api/health` for readiness and alert on HTTP 5xx rates or `status: "degraded"`.

# FormForge AI — Universal PDF-to-AcroForm Conversion & Document Automation

ALV Form Online now includes **FormForge AI Studio** (accessible via the top navigation bar or `FormForge AI Studio` tab), implementing two strictly separated processing engines:

1. **Engine A — Conversion Studio (`/api/v1/documents/*`, `/api/v1/templates/*`, `python/formforge_engine.py`)**:
   - Ingests native digital PDFs, scanned image-only PDFs, and mixed documents across A4, A3, A5, Letter, Legal, and custom page sizes.
   - Sanitizes active PDF scripts/triggers (`/JS`, `/JavaScript`, `/OpenAction`, `/AA`) upon conversion.
   - Runs **PyMuPDF + pdfplumber + OpenCV morphological preprocessing + Tesseract OCR** (`eng`) to detect 16 field types (including grouped `char_cells` boxes) with evidence-based confidence scoring (`high`, `medium`, `low`).
   - Provides a real **PDF.js Visual Field Editor** (`src/components/studio/PdfFieldEditor.tsx`) with reversible coordinate transforms (`src/lib/formforge/coordinate.ts`), drag/resize/draw tools, undo/redo, and property inspector.
   - Generates real AcroForm PDFs with `/AP` appearance streams, executes `pypdf` + PyMuPDF structural validation, tracks version diffs, and enforces dual-check (`structuralVerified` + `visualVerified`) template approval before locking.
2. **Engine B — Independent Customer Rendering & Submission (`/api/v1/render/:templateId`)**:
   - Consumes only **approved** templates (`tpl_alv_official` is seeded out-of-the-box without altering any ALV coordinates).
   - Dynamically generates multi-type forms from `FieldManifest`, populates AcroForm widgets and character-cell arrays, regenerates appearance streams, **flattens PDFs by default** so private fillable masters stay protected, and accepts physically signed PDF uploads.

## Authentication, RBAC & First-Run Admin Claim

- If `FORMFORGE_ADMIN_PASSWORD` is unset, open **FormForge AI Studio** and use the one-time **Claim FormForge AI Administrator** screen (`POST /api/v1/auth/bootstrap`). Once claimed, public registration locks automatically.
- Six enforced RBAC profiles: `administrator`, `template_manager`, `editor`, `reviewer`, `api_integration_user`, `read_only_user`.
- Programmatic integrations authenticate with scoped keys (`X-API-Key: ffk_...`) created in **API & Integrations**.
- Interactive OpenAPI 3.1 schema: `GET /api/v1/openapi.json`.

## Backup, Recovery & Troubleshooting

- **Backups**: Snapshot `storage/formforge/` (database `formforge.db` + `originals/`, `acroforms/`, `renders/`, `signed/`) or run `pg_dump` against `DATABASE_URL`.
- **OCR slow or missing**: Verify `tesseract --version` and ensure `PYTHON_TIMEOUT_MS` is set to at least `60000` for multi-page scanned documents.
- **Coordinate drift checks**: Every manifest field stores `top_left_pdf_pt` coordinates relative to the effective CropBox; run `npm test` to verify coordinate round-trips and real PDF AcroForm widget generation.
